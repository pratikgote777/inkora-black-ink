# INKORA Black Ink — Product Website

> *"Every Drop Tells a Story."*

A modern, responsive editorial product website for **INKORA Black Ink**, a student-developed writing ink created as part of a practical chemistry and engineering curriculum at **MIT Academy of Engineering (MIT AOE), School of Chemical Engineering, Pune**.

---

## 🧪 About the Project

INKORA explores the organometallic coordination chemistry of historical iron-gall inks using everyday botanical polyphenols and laboratory reagents:
- **Chromophore Matrix**: Aqueous synthesis combining iron(II) sulfate heptahydrate ($\text{FeSO}_4\cdot 7\text{H}_2\text{O}$) with heated black tea tannin extract to produce an intensely opaque black iron-gallate complex.
- **Colloidal Stabilization**: Natural Acacia Gum Arabic functions as a protective colloid and binder, maintaining microscopic particle suspension and paper adhesion.
- **Fluid Viscosity**: Laboratory-grade glycerine regulates capillary flow for consistent dip-pen and glass nib delivery.

---

## ✨ Features

- **Dark Editorial Aesthetic**: Deep charcoal (`#090A0C`), muted graphite, and silver accents with high-contrast light studio product showcases.
- **Decongested Navigation**: Categorized dropdown menus (*Formulation* and *Cost & Product*) with an interactive top scroll progress indicator.
- **Hardware-Accelerated Scroll Animations**: Subtle intersection-observed reveals, scale effects, and staggered transitions.
- **Physical Product Photography**: Features authentic laboratory specimen photos on MIT AOE chemical engineering bench tops.
- **Production Cost Breakdown ("Where Every Rupee Goes")**: Static, transparent unit economics detailing ingredient and consumable costs per batch.
- **Product Showcase ("Meet Our Product")**: Amazon/Flipkart-inspired product listing card with verified specifications and direct academic inquiry routing.
- **Interactive Lab Log**: Practical observation journal tracking color, volume, drying time, and compatibility across paper grades.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/pratikgote777/inkora-black-ink.git

# Navigate to project directory
cd inkora-black-ink

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

### Production Build & Linting

```bash
# Code quality check with Oxlint
npm run lint

# Build production bundle
npm run build
```
